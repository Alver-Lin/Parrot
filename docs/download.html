当前发行包使用开发签名、未经 Apple 公证。若系统提示无法打开：打开「系统设置 → 隐私与安全性」允许仍要打开，或按住 Control 点击安装包后选择「打开」。

安装引导

  1. 点击上方按钮下载 Parrot-1.0.0-arm64.pkg（Intel Mac 需对应架构包）。
  2. 双击打开安装包，按安装器提示继续；需要管理员密码以写入「应用程序」。
  3. 升级时安装器会先退出旧版并删除 /Applications/Parrot.app，再写入新版本。
  4. 安装完成后从「启动台」或「应用程序」打开 Parrot；首次使用需授权麦克风 / 系统音频。
  5. 识别模型首次使用时在设置中下载；数据保存在 ~/Library/Application Support/Parrot。
