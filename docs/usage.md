# Parrot 使用与构建指南

[返回项目首页](../README.md)

Parrot 是一个 macOS 语音转写客户端。点击屏幕上的悬浮球展开转写面板，把电脑播放的课程声音转为文字，再校对、复制或导出 Markdown。

## 使用方式

构建完成后，双击 `dist/Parrot.app`。客户端启动时只显示悬浮球和菜单栏图标，不需要打开浏览器或单独启动后端。

1. 点击悬浮球展开面板，可拖动到屏幕任意位置，松开后保持原位，并记住位置供下次启动恢复。
2. 从顶部齿轮进入识别设置，选择音频来源、语言、模型和推理引擎。音频来源提供「识别麦克风音频」「识别本机音频」「识别麦克风与本机音频」，默认本机音频，选择会在下次启动时保留。双声源模式建议戴耳机，避免电脑外放被麦克风重复采集。未下载的模型会显示「下载模型」按钮；已下载时显示「模型已下载」，隐藏下载按钮，开始转写时自动从本地载入。
   设置底部显示当前音频来源的授权状态和所选模型的下载状态：绿色圆圈表示已就绪，红色叉号表示未授权、未下载或下载失败。点击「前往授权」可请求权限或进入对应的系统设置，点击「下载模型」可直接下载，失败后可重试。查看状态不会自动请求权限。
   「AI 润色」区域可录入 OpenAI 兼容的 Base URL、API Key 和模型名称，只需点击「测试连接」即可自动保存并查看连接状态，测试失败也保留已保存的配置。密钥仍存入 macOS 登录钥匙串，读取和保存禁止弹出认证窗口。旧版条目能静默读取时自动迁移；旧权限不允许读取时跳过，重新录入一次 Key 并测试连接即可保存到新版条目。重启应用后 Key 会回填到可编辑输入框，点击眼睛随时切换显示或隐藏；关闭设置保留当前编辑内容和显示状态。清空输入框不会删除已保存的 Key，输入新 Key 后点击测试连接才会替换。测试只发送简短固定请求，不发送文稿、音频或截图；本机兼容服务支持免密钥。底部分开展示「识别模型已下载」和「润色模型已连接」：API 模型无需下载，更换配置后需要重新测试，重新启动客户端后也需重新测试连接。
3. 点击「开始聆听」，看到「正在聆听」后再播放电脑中的课程。戴耳机也可使用。
4. 再次点击悬浮球、右上角收起按钮或窗口关闭按钮，面板会隐藏，后台继续转写。
5. 停止后等待剩余转写完成，校对文字。在 Markdown 页可直接编辑全文，修改会自动保存，也可按 ⌘S 保存。点击「复制全文」或「导出」使用当前编辑内容。
6. 历史记录从顶部时钟图标打开；退出程序请使用菜单栏 Parrot 图标中的「退出 Parrot」。

开始聆听或续写当前记录后，底部计时右侧会显示相机按钮，暂停期间也可截图，停止后隐藏。点击相机按钮可以框选屏幕截图。看板会先自动收起，截图完成后保持收起；再次点击悬浮球即可看到插入的图片，点击图片可放大查看。截图也会写入 Markdown 的相对图片引用。按 Esc 取消截图，不会插入内容。

从桌面客户端导出时，图片保存在 `.md` 文件旁的 `photo/` 文件夹，移动或分享笔记时请带上这个文件夹。独立浏览器开发模式导出含图片的文稿时，会下载包含 Markdown 和 `photo/` 的 ZIP 包。

打开历史记录后，底部麦克风用于续写当前记录，沿用该记录的识别参数。新文字接在原文后，时长和时间戳继续累计；已编辑的 Markdown 会保留并追加新文字。需要一条独立记录时，先点击顶部「新建」。

历史记录名称取 Markdown 开头的一级标题（`# 标题`），修改后会随自动保存同步更新；没有有效一级标题时保留原名称。此前已编辑的文稿也会按该标题显示。

Markdown 创建时间、历史列表日期和新记录标题日期统一按北京时间（Asia/Shanghai）显示。创建时间使用“2026-11-19 23:20:28（北京时间）”的格式；重启时会将历史文稿中原先自动生成的 UTC 创建时间行转换为相同格式，保留手写日期、正文示例与润色撤销功能。

转写结束后，Markdown 页「复制全文」左侧的「AI 润色」会将口播整理成学习笔记：清除无关口播、机械重复和明显识别噪声，依据上下文或截图修正有证据的术语错误，自动生成主题标题与章节，并保留关键例子、数字、单位和适用条件。材料截断时简短说明范围，不根据课程预告补写完整内容；无法确定的术语沿用原文，不附加结果核对报告。提示词按 `video-to-study-notes` skill 改编，并明确区分原文、截图证据与额外知识。

点击后预览原文，再点击「开始润色」。标题、正文和本地 PNG 截图预览会发送给所配置的 API，含图记录需要模型支持 `image_url` 图文输入；模型根据截图实际内容，将图片放到相关概念、步骤或结果旁，必要时补充图注。仅发送最长边不超过 2048 像素的预览，原始图片文件不变。链接、代码、表格、公式和记录元信息以占位符留在本机，返回后恢复原文；图片引用和原始时间标签保留。外部图片或不支持的图片引用保留，不作为模型识图附件上传；预览支持显示常规网络图片。

短文整篇整理，长文按约 8000 字符分批，每批可以合并段落、重排列表和截图，并参考前批标题衔接；跨批图片不移动。支持进度显示与取消。润色结果直接展示，不因代码、表格、链接、图片、公式、标题层级或占位符变化而拦截；遗漏的原有本地资料会自动恢复。兼容 JSON 包装和直接返回的 Markdown，服务返回已有文字时可展示长度截断结果。生成后直接展示学习笔记，不进行数字差异对照或显示结果核对提醒。正文二级标题统一编号为“一、二、三……”，三级标题使用“（一）（二）（三）”，分批生成后统一连续编号。接口不兼容图文输入时提示更换支持视觉的模型，不将无图输出冒充识图结果。

返回后展示原始版本与润色结果，点击「应用润色」才写入 Markdown，并同步记录标题。第一次成功应用时，单独保存润色前的文稿与标题；此后每次润色都读取这份原始版本，不使用上一次润色结果。点击「恢复原始版本」直接还原这份原稿及标题，不逐次回退；重启后仍保留原稿，旧记录自动从最早一次润色历史中恢复原稿。继续录制新增的转写和截图、截图替换及删除会同步到原始资料中。原始转写段落及截图文件不受润色影响。生成期间的新修改仍通过并发检查保护；恢复时若当前文稿有已保存的手工修改，先存入内部历史再还原原稿，未保存的修改需先保存。

关闭面板不会退出客户端。退出客户端时会停止声音采集并等待剩余转写，超过 30 秒仍未结束时提供继续等待或立即退出的选择。

## 1.0 功能范围

- 可自由放置、记住位置并置顶的原生悬浮球，点击展开与收起转写面板。
- 转写内容与 Markdown 双标签，历史记录与识别设置弹窗。
- macOS 13+ 麦克风、本机声音及双声源混音采集，不需要虚拟声卡。
- Whisper 本地中英文识别，Apple Silicon 优先 MLX，其他环境使用 faster-whisper CPU int8。
- 静音过滤、时间标记、建议校对提示、逐段修改和历史记录续写。
- 手动选区截图、转写图片预览，以及 Markdown 与 `photo/` 图片目录一起导出。
- Markdown 全文编辑与自动保存、系统剪贴板复制、系统保存对话框导出；默认正文没有片段时间戳与空白行，保留英文单词之间的空格。编辑后的 Markdown 作为独立文稿保存，原始转写仍保留在「转写内容」页；建议转写完成后整理文稿。
- 持久保存文字、手动截图与元信息，识别用临时音频片段在任务结束时清理。

1.0 不提供音频/视频文件导入、原始录音保存或回听。旧版本已生成的录音文件不会自动删除，也不通过客户端提供访问。自动截图与独立复习卡片尚未实现；AI 润色可按内容生成学习笔记与章节。

## 下载安装（推荐）

macOS 13+ 可直接安装发行包（当前提供 Apple Silicon / arm64）：

1. 打开引导页：[下载引导页](download.html)，或前往 [GitHub Releases](https://github.com/Alver-Lin/Parrot/releases/latest)。
2. 下载 `Parrot-1.0.2-arm64.pkg`，双击按提示安装到「应用程序」。
3. 再次安装更高版本时，安装器会先退出并移除旧的 `/Applications/Parrot.app`，再写入新版本；`~/Library/Application Support/Parrot` 中的个人数据会保留。

若系统提示无法打开未公证的安装包：打开「系统设置 → 隐私与安全性」允许仍要打开，或按住 Control 点击 `.pkg` 后选择「打开」。

## 安装与构建（开发）

当前开发构建依赖项目现有的 Python 环境与数据目录。对外分发请使用 `scripts/build-release.py` 生成捆绑 Python 的 `.pkg`。

需要 macOS 13+、Xcode Command Line Tools、Python 3.9+（建议 3.11/3.12），以及满足 Vite 要求的 Node.js 20.19 系列或 22.12 以上版本。

首次安装开发环境：

```bash
bash scripts/setup.sh
```

启动：双击 `dist/Parrot.app`，或运行：

```bash
bash scripts/start.sh
```

也可双击项目根目录 `start.command`。客户端需要重建时，先从菜单栏退出 Parrot，再运行：

```bash
cd frontend
npm ci
npm run build
cd ..
.venv/bin/python scripts/build-client.py
```

`scripts/build-client.py` 编译原生窗口和声音采集组件，复制后端与前端资源，生成应用图标，使用固定证书分别签名采集组件和主应用。输出位于 `dist/Parrot.app`，用户数据不写入应用包。

制作可安装的发行包（捆绑 Python，安装到 `/Applications`，升级时卸载旧版应用）：

```bash
cd frontend && npm run build && cd ..
PARROT_VERSION=1.0.2 .venv/bin/python scripts/build-release.py
```

产物位于 `dist/release/Parrot-1.0.2-<arch>.pkg`。用户数据目录为 `~/Library/Application Support/Parrot`，不会写入应用包。

本机已有旧项目时，先运行 `.venv/bin/python scripts/setup-signing.py` 初始化一次签名身份。不要删除 `.data/signing/` 或将其中的密钥、密码提交到版本库。构建失败会保留原应用，不会自动降级为临时签名。

有 Apple 证书时，可设置 `PARROT_SIGNING_IDENTITY`（证书 SHA-1 或名称）和可选的 `PARROT_SIGNING_KEYCHAIN`。只有明确设置 `PARROT_ALLOW_ADHOC=1` 才能构建临时签名测试包，该包不能保证权限连续性。

## 音频与截图权限

首次使用所选音频来源或截图时，按 macOS 提示授权。本机声音与截图的权限在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」中管理，必要时退出并重新打开客户端。

麦克风模式仅请求麦克风权限，不要求系统声音权限；本机音频模式仅请求系统声音权限；双声源模式需要两项权限。麦克风使用 macOS 当前默认输入设备，可在「系统设置 → 声音 → 输入」中切换后重新开始或暂停再继续。截图仍需屏幕录制权限。

从原网页开发模式或旧 ad-hoc 构建切换后，需要为当前 Parrot 重新授权一次。后续构建复用固定证书和 Bundle ID。首次安装会在 `.data/signing/` 创建本地开发签名钥匙串；不安装系统信任根，也不用于对外分发。若该目录丢失或更换签名证书，需要重新授权。只有选择麦克风或双声源模式时才采集麦克风；只有点击截图按钮并完成选区时，才保存该次手动截图。

带 DRM 保护的媒体可能禁止采集。当前原生客户端不支持 Windows 或 Linux。

## 模型与准确率

默认模型是 Whisper large-v3，优先识别质量；Turbo 更快，Small 更省资源。Apple Silicon 在安装 MLX Whisper 时自动选择 MLX，否则使用 faster-whisper CPU int8。加载失败不会自动切换引擎，可以在设置中选择其他引擎重试。

中文课程选择中文，英语课程选择英语，不确定时选择自动检测。首次下载模型需要网络，Large v3 的历史缓存大小约 2.9GB；下载过程可查看 `.data/desktop.log`。

聆听时可点击描边圆形按钮暂停，再点击继续接着同一条记录转写。暂停期间不采集声音、计时不增加；已采集的文字仍会处理。实心方框按钮用于结束记录。

Whisper 为分段识别，通常积累 8–24 秒音频后输出一批文字；实际延迟还取决于设备与模型。收起面板后采集和识别继续，较慢设备可能积压待处理片段，停止后仍需等待剩余识别。

没有模型能保证零错误。「建议校对」是启发式提示，不是准确率分数；没有标记的段落也可能出错。当前未在正式课程标注集上测定统一字错率。

## 数据与本地服务

本机构建默认使用项目 `.data/`，安装包使用 `~/Library/Application Support/Parrot`，两边互不共用。若安装版目录尚无学习记录，启动时会尝试从旧版项目 `.data/` 自动导入一次；导入后仍各自独立写入。`soundscribe.db` 保存文字和记录；`<记录ID>/chunk-*.wav` 是识别临时片段；`models/` 缓存模型。备份前先退出客户端，再复制数据目录。

客户端自动启动独占的 Python 服务，使用随机回环端口和每次启动生成的访问令牌。转写与模型接口需要令牌，不作为日常浏览器入口。客户端退出时结束自己启动的服务；原生宿主异常消失时，后台所有者监控会尝试退出服务。

`desktop.log` 保存后台日志，`desktop-state.json` 保存运行进程、端口和窗口可见状态供诊断，不包含访问令牌。模型下载会联网，识别过程不上传音频。

可选环境变量：`PARROT_DATA` 指定数据目录，`PARROT_PYTHON` 指定构建/测试使用的 Python 解释器。旧变量 `SOUNDSCRIBE_DATA` 仅在直接运行后端的兼容场景保留；客户端优先使用应用包记录的路径或 `PARROT_DATA`。

## 开发与验证

后端测试和静态检查：

```bash
.venv/bin/python -m pip install -r backend/requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m ruff check backend tests scripts
```

原生客户端集成验证（需 macOS 图形会话，会短暂显示测试悬浮球和面板，使用独立临时数据）：

```bash
.venv/bin/python scripts/test-client.py
```

验证覆盖真实 AppKit 窗口、拖动边界、展开收起、后台服务、WebKit 桥接、原生复制与导出、历史记录、设置及访问令牌。截图位于 `.data/client-test-artifacts/`。正常测试使用合成音频验证混音与时间线，不采集真实声音，也不修改实际历史记录。

仅调试 Vue 界面时，可以在一个终端运行 `bash scripts/start-backend.sh`，另一个终端在 `frontend` 中执行 `npm run dev`，访问本机 5173 开发地址。该模式用于开发，未启用原生悬浮球和客户端令牌。不要与使用同一数据目录的正式客户端同时运行后端；需要并行测试时设置独立 `PARROT_DATA`。

详细设计见 [开发文档目录](README.md) 和 [客户端设计文档](客户端设计文档.md)。前端构建依赖历史公告及此前样本限制见 [验证记录](VALIDATION.md)，发布时应重新审查依赖。
