## 取消设置中的钥匙串认证弹窗（2026-11-20）

API Key 继续保存在登录钥匙串，不改为明文偏好设置。旧式登录钥匙串 ACL 不受单独的 `LAContext.interactionNotAllowed` 完整约束，因此同步读写时暂时禁用旧式钥匙串 UI，完成后立即恢复进程原设置，不在网络请求期间保留该开关。新版使用独立服务条目，旧条目已有访问权限时静默迁移；无权限时直接跳过，保留旧条目，用户重新输入一次 Key 后通过测试连接保存到新版条目。

固定证书签名构建、Ruff 和原生客户端自检通过。跨进程测试使用 UUID 隔离的临时条目，特意创建不信任任何应用的旧 ACL，验证读取不会弹窗且会跳过，并验证重新录入后正常保存、可访问的旧条目静默迁移、替换后重启保留、空白保留以及偏好设置不含明文 Key。临时条目全部清理；没有访问用户的实际 Key。界面自检保留自动保存、直接编辑、显示隐藏及连接状态覆盖。

前端类型检查与生产构建、Ruff、固定证书签名构建和原生客户端自检通过。界面自检覆盖没有保存按钮、测试自动保存、Key 回填和显示隐藏、关闭后重开保留显示、空白保留、新 Key 替换，以及鉴权失败时配置仍保存且显示红色失败状态。隔离的真实钥匙串跨进程持久化验证通过；界面使用测试 Key 和模拟 API，没有读取用户的真实配置或调用真实供应商。

## API Key 显示与持久保留（2026-11-20）

已保存的 Key 默认用圆点展示，眼睛按钮按需从钥匙串读取完整值；显示操作不会把 Key 标记为待保存的新值。再次点击眼睛、关闭设置或切换 API 地址时隐藏已读取的值。移除原来的删除密钥入口，空白输入（含旧客户端的删除标志）保留钥匙串中的 Key，只有录入非空新 Key 并保存才替换。钥匙串需要交互解锁时不再误报为未保存；普通配置读取仍不返回密钥。

前端类型检查、生产构建、Ruff、固定证书签名构建及原生客户端自检通过。新增独立签名进程测试，使用 UUID 隔离的偏好设置和真实登录钥匙串条目，验证保存后退出再启动、清空后保存、替换后再次启动都能读取正确 Key，且普通偏好设置不含密钥；测试结束清理临时条目。界面自检覆盖按需显示、隐藏、查看不造成配置变更、关闭后重开保持隐藏、空白保留和新 Key 替换。没有读取、显示或修改用户的真实 Key，也没有调用真实供应商 API。

## AI 文稿润色与图片保护（2026-11-20）

Markdown 页新增「AI 润色」。操作先显示 API 服务商、模型和发送范围，确认开始后仅发送可润色文字，按段落编号分批处理并报告进度，可取消。固定提示词要求去口语和明显重复、保留事实与限定关系，不做摘要。结果先与原文对照预览，点击应用后才写入 Markdown；原始转写段落不变。本地保存应用前后的版本，支持撤销，应用和撤销都使用事务与原文一致性检查，避免覆盖并行编辑或转写。

图片、含图片的整个段落、链接、代码、表格、标题及元信息留在本机。程序按原位置恢复这些内容，保留原始换行和相对图片引用，不上传图片、不读图或 OCR，不改变图片文件。模型遗漏段落、重复编号、返回截断内容、新增图片或改变列表结构时拒绝结果；数字变化会提示人工核对。

70 项后端测试、5 项 Markdown 保护测试、前端类型检查和生产构建、Ruff、签名构建与原生客户端自检通过。验证覆盖 CRLF、行内与引用图片、含图列表、代码与公式、长文分块、生成图片或链接的拒绝、数字变更提示、并行修改冲突、版本持久化与撤销、删除记录后的版本清理。原生界面自检验证按钮位置、预览不自动覆盖、原文/结果两侧显示同一截图、API 请求不含截图引用、应用后可撤销，且截图二进制完全一致。使用隔离数据与模拟 API，未发送真实文稿或使用真实 API Key；实际模型润色质量需要用户预览校对。

## AI 润色接口配置（2026-11-20）

识别设置新增 OpenAI Chat Completions 兼容的 API 地址、API Key、模型名称、保存配置和测试连接。API Key 按归一化接口地址分别存入 macOS 登录钥匙串，界面与配置读取接口只返回是否已保存，空白密钥保留已有值，支持显式移除。不同地址不自动复用密钥；远程地址要求 HTTPS，本机回环地址支持 HTTP。连接测试不跟随重定向，只发送简短固定文本，并校验 Chat Completions 响应；支持不兼容 Token 参数的回退及常见 HTTP 错误提示。底部区分识别模型下载状态与润色模型连接状态，API 模型不标记为已下载。

前端类型检查、生产构建、Ruff、签名构建和原生客户端自检通过。原生自检使用内存中的模拟密钥与响应，覆盖地址归一化、密钥不回传、按地址隔离、空白保留与显式移除、Bearer 鉴权、Token 参数回退、401/403/404/429/503/302、无效响应和本机免密钥接口。界面自检覆盖配置输入、保存、密码框遮盖、测试成功绿色圆圈、鉴权失败红叉，以及识别/润色状态区分；不使用真实 API Key、不调用真实供应商、不改写文稿。实际供应商连通性和登录钥匙串读写需用户录入真实配置后验证。

## 三种音频来源（2026-11-20）

识别设置新增「识别麦克风音频」「识别本机音频」「识别麦克风与本机音频」。默认本机音频，所选来源在客户端重启后保留，新记录保存来源，暂停恢复和历史续写沿用该记录来源。旧记录迁移为本机音频。麦克风模式通过 AVFoundation 采集默认输入设备，本机音频沿用 ScreenCaptureKit，双声源按共同时间线混音为 16 kHz 单声道 PCM，避免时长翻倍；停止和暂停时输出延迟缓冲中的尾部音频。
