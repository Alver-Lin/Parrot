# 验证记录

## 手动截图与图片导出（2026-11-20）

底部控制条新增相机按钮。用户触发后隐藏看板和悬浮球，再调用系统选区截图；完成后恢复悬浮球，看板保持收起。截图作为带时间点的图片段落保存，插入转写列表并同步 Markdown 图片引用。桌面导出在 Markdown 旁写入 `photo/`，浏览器开发模式导出包含二者的 ZIP；图片请求使用私有令牌，不把令牌放进图片 URL。

47 项后端测试、Ruff、前端构建通过。测试覆盖截图文件校验、大小限制、时间顺序、文稿并行保存合并、图片目录导出、记录访问范围及删除清理。原生客户端自检使用合成图片验证按钮、自动收起、图片读取预览和导出的实际 Markdown/PNG 文件一致性；没有截取真实桌面、录制声音或修改实际历史记录。系统选区交互及首次授权仍需用户在实际桌面操作。

## 历史记录续写（2026-11-19）

历史记录中的麦克风现在续写同一条记录，顶部「新建」仍创建独立记录。后端保留记录 ID、创建时间、原文与校对结果，沿用该记录的识别参数；音频采样偏移从原累计时长接续，临时片段仍在结束后清理。已编辑的 Markdown 保留原稿并追加新转写；保存时合并输入期间到达的新文字，避免覆盖续写内容。

37 项后端测试通过，包含完成、失败、中断记录的重复续写、时长和时间戳累计、活动任务互斥、历史内容保留，以及文稿并行编辑合并。Vue/TypeScript 类型检查、Vite 生产构建和 Ruff 检查通过。

## Markdown 直接编辑（2026-11-19）

Markdown 页改为可输入的全文编辑区，停止输入 600ms 后自动保存，失焦及 ⌘S / Ctrl+S 也会保存。文稿独立持久化，原始转写保留；复制及浏览器、原生导出使用当前编辑内容。保存失败时保留本次草稿并提供重试入口。旧数据库自动添加可空文稿列，未编辑的记录继续从转写生成 Markdown。

31 项后端测试通过，覆盖旧数据库迁移、文稿持久化、空文稿、原始转写保留及导出一致性；Ruff 和前端类型检查、生产构建通过。隔离数据的原生客户端自检覆盖直接输入、自动保存后继续编辑、复制、导出及后台轮询期间内容保留。

## 1.0 版本范围更新（2026-11-19）

1.0 仅提供 macOS 系统声音转写，已移除导入入口、上传接口、文件解码分支和命令行文件识别。已有历史文字与录音继续保留。当前测试覆盖系统声音任务到回听、校对和导出的链路，以及旧上传接口不可用的回归检查；历史准确率样本不等于 1.0 的新一轮准确率评估。

## 1.0 原始录音功能移除（2026-11-19）

不再展示原始录音播放器、提供回听或录音接口，新任务只保存文字与元信息。识别用临时片段在任务退出时清理；已有历史录音文件不自动删除，也不通过接口提供访问。回归测试覆盖真实采集管道的尾部识别与无完整录音落盘、失败后排队片段清理，以及旧录音接口不可访问。

## macOS 客户端改造（2026-11-19）

默认产品入口变更为原生 `.app`。新增左侧可拖动悬浮球、点击展开/收起、紧凑转写与 Markdown 面板、原生剪贴板及保存对话框桥接、私有回环服务令牌和宿主退出管理。17 项后端测试通过；原生客户端自检使用隔离数据，已验证真实窗口、拖动边界、展开收起、后台存活、桥接复制/导出、设置和鉴权，未自动录制用户声音。当前打包依赖本机 Python 环境与模型缓存，尚未验证跨机器安装、真实课程长期稳定性及各版本 macOS 的权限表现。详细设计见 `doc/客户端设计文档.md`。
